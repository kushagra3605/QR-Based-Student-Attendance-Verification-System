# QR-Based Student Attendance Verification System

A simple and efficient **QR-Based Student Attendance Verification System** built using **HTML, CSS, and JavaScript**.

The system allows users to generate unique QR codes for students using their name and enrollment number. These QR codes can then be scanned using a device camera to verify and record student attendance.

> ⚡ This project works entirely in the browser and does not require a backend or database server.

---

## 🚀 Features

### 👨‍🎓 Student QR Generation

* Generate a unique QR code using:

  * Student Name
  * Enrollment Number
* One-time QR generation for each enrollment number.
* Download generated QR codes as PNG images.
* Prevents duplicate QR generation.

### 📷 QR Code Scanner

* Scan QR codes using the device camera.
* Automatically verifies whether the QR code was generated by the system.
* Marks a student as checked after a successful scan.
* Prevents duplicate attendance entries.
* Stops scanning after detecting a QR code.

### 🛠️ Admin Panel

* Generate QR codes for students.
* View the list of scanned students.
* View scan timestamps.
* Reset individual students so they can be scanned again.
* Reset all scanned records.
* Clear all generated QR records.

### 🔐 Basic Access Protection

* Separate password-protected access for:

  * Admin Panel
  * QR Scanner
* Authentication remains active only during the current browser session.

> **Note:** The authentication system is implemented on the frontend and is not suitable for production-level security.

### 💾 Local Data Storage

* Uses the browser's `localStorage` to store:

  * Generated QR records
  * Checked student records
* No external database or backend is required.

## ⚙️ How It Works

### 1. Generate a QR Code

1. Open `index.html`.
2. Enter the student's **Full Name**.
3. Enter the student's **Enrollment Number**.
4. Click **Generate QR**.
5. A unique QR code will be generated.
6. Download the QR code if required.

Each enrollment number can have only one generated QR code unless the generated records are cleared.

---

### 2. Scan the QR Code

1. Open the **Scanner** page.
2. Enter the scanner password.
3. Click **Start Camera Scan**.
4. Allow camera access when prompted.
5. Scan the student's QR code.
6. The system verifies the QR code and marks the student as checked.

If the student has already been scanned, the system displays:

```text
Student already scanned
```

---

### 3. Admin Controls

The admin panel provides the following features:

* Generate student QR codes
* View scanned students
* View attendance timestamps
* Reset individual student attendance
* Reset all scanned students
* Clear all generated QR records
* Open the QR scanner

## 💻 Installation and Usage

### Method 1: Run Directly

1. Download or clone this repository.

```bash
git clone <repository-url>
```

2. Open the project folder.

```bash
cd QR-Based-Student-Attendance-Verification-System
```

3. Open `index.html` in your browser.

---

### Method 2: Using VS Code Live Server

For the best experience:

1. Open the project in **Visual Studio Code**.
2. Install the **Live Server** extension.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.

This is especially useful for camera permissions required by the QR scanner.

## 📱 Important Notes

* The scanner requires access to the device camera.
* Attendance data is stored only in the current browser using `localStorage`.
* Data will not automatically sync between different devices or browsers.
* Clearing browser storage may remove all generated and attendance records.
* The authentication system is frontend-based and intended for demonstration or educational purposes.

## 🎯 Project Purpose

The purpose of this project is to demonstrate how QR technology can be used to simplify and automate the student attendance verification process.

* Generating student-specific QR codes
* Verifying QR codes
* Preventing duplicate attendance
* Managing attendance records through an admin panel
